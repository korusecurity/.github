# Security Policy

This is the default security policy for repositories in the Koru Security organization. A
repository that has its own `SECURITY.md` follows that file instead; for Koru itself, see
[SECURITY.md in the koru repository](https://github.com/korusecurity/koru/blob/main/SECURITY.md).

## Reporting a vulnerability

Report vulnerabilities privately to security@korusecurity.com, or use GitHub private
vulnerability reporting on the affected repository. Please do not open public issues,
pull requests or discussions for security reports.

Include the affected version or commit, a short description, reproduction steps and the
estimated impact. Do not attach real secrets or third parties' personal data.

## Supported versions

Only the latest release and the `main` branch receive security fixes.
